# Patanegra Central

Sistema de pedidos para clientes de comércio da **Patanegra** — plataforma B2B para bares, restaurantes e estabelecimentos realizarem pedidos de chopp e produtos, com controle interno de demanda.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS

## Rodar Localmente

**Pré-requisitos:** Node.js

1. Instalar dependências:
   ```bash
   npm install
   ```
2. Configurar `GEMINI_API_KEY` em [.env.local](.env.local) (se necessário)
3. Rodar o app:
   ```bash
   npm run dev
   ```

## Deploy

Deploy automático via **Vercel** conectado a este repositório.
